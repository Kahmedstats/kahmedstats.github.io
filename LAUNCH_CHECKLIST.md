# Pre-Publication Checklist — Postdoctoral Research Website

- [ ] Replace every bracketed placeholder throughout all HTML pages.
- [ ] Use the degree designation you actually hold (e.g., “PhD Candidate” only when accurate).
- [ ] Confirm the official institution and department names.
- [ ] State a precise research question, your specific role, methods and significance.
- [ ] Verify publication metadata, exact DOI, authorship, publication type and permissions.
- [ ] Link only to research code, datasets or documents cleared for public release.
- [ ] Present preprints as preprints; do not imply peer review where none occurred.
- [ ] Remove sections with no verified content rather than filling them with invented claims.
- [ ] Ensure any photograph or graphic has the right permissions.
- [ ] Review email, CV, addresses and links for privacy before public upload.
- [ ] Test navigation, mobile menu, color contrast, keyboard focus and dark mode.
- [ ] Test the publications filter and the CV print-to-PDF feature.
- [ ] Review spelling, dates, capitalization, and academic title consistency.
- [ ] Upload files to the repository root; select branch publishing from `main` / `(root)`.
- [ ] Confirm the live site loads at `https://YOUR-USERNAME.github.io/`.
- [ ] Add your live website URL to your GitHub profile README and academic CV.
- [ ] Review the site after major paper acceptances, job changes and degree milestones.
